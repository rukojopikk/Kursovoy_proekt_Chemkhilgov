# Методика разработки

## Подход
Система использует реляционную модель данных.

## Основные сущности
- Book — каталог электронных книг
- User — зарегистрированные пользователи
- Order — покупки и аренда книг
- Subscription — подписки пользователей
- ReadingProgress — прогресс чтения по каждой книге

## Инструменты
Реляционная СУБД (PostgreSQL/SQLite), веб-интерфейс.

# Постановка задачи

## Актуальность
Рост потребления цифрового контента требует удобных платформ для доступа
к электронным книгам. Существующие решения часто не обеспечивают
персонализацию и качественный UX читалки.

## Ограничения
- Данные: демонстрационный набор книг и пользователей (не реальная база)
- Инструменты: реляционная СУБД (PostgreSQL/SQLite), веб-интерфейс
- Предметная область: публичный каталог книг, без DRM-ограничений

## Критерии успешности
1. Основная метрика «завершённые чтения» растёт после улучшения рекомендаций
2. Конверсия из просмотра в покупку превышает 5%
3. Удержание пользователей на 7-й день выше 40%

## Риски
- Риск: недостаточный объём демо-данных → снижение: генерация синтетических данных
- Риск: сложность алгоритма рекомендаций → снижение: простая коллаборативная фильтрация

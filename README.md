# Информационная система электронной библиотеки

## Назначение проекта
Проект представляет собой ИС онлайн-библиотеки (BookStore Master) с каталогом
электронных книг, возможностью покупки и аренды, персональными рекомендациями
и встроенной читалкой. Цель — обеспечить пользователям быстрый доступ
к качественному книжному контенту и комфортный процесс чтения.

## Состав репозитория
- docs/     — техническое задание, модель БД, сценарии пользователей;
- src/      — SQL-скрипты, прототипы, демонстрационные данные;
- sql/      — DDL/DML скрипты схемы базы данных;
- data/sample/ — небольшой пример данных (книги, пользователи);
- experiments/ — журнал проверок и итерации по метрикам;
- assets/   — схемы, диаграммы, макеты интерфейса.

## План выполнения
1. Постановка задачи и анализ предметной области.
2. Проектирование модели данных (ER-диаграмма, схема БД).
3. Описание сценариев пользователей и макетов.
4. Определение метрик продукта и их связи с системой.
5. Подготовка пояснительной записки.

## Текущий статус
Сформирована постановка задачи, создана структура репозитория.
